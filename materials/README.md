# Исходные материалы завода

Сюда кладутся документы, на которые ссылается таблица утверждений.
Без документа-источника ни одна фраза не идёт в тексты.

## Что положить

Документы (PDF или сканы, все страницы):

- [ ] СГР на БАД
- [ ] СГР или декларация на лосьон, если уже есть
- [ ] Протоколы испытаний
- [ ] Патент (полный текст с формулой)
- [ ] Текущая этикетка БАД (макет или фото всех сторон)
- [ ] Состав лосьона по INCI, если этикетка лосьона входит в работу

Файл `facts.md` (простой текст):

- [ ] Название завода (юрлицо, ИНН, адрес производства)
- [ ] Название продукта, как в СГР, и торговое название
- [ ] Объём банки: сколько капсул / граммов
- [ ] Дозировка: сколько в сутки и сколько дней курс, по СГР
- [ ] Цены: банка БАД, лосьон; на каждом маркетплейсе
- [ ] Ссылки на карточки маркетплейсов
- [ ] Учёные: ФИО, степень, должность, согласие на упоминание
- [ ] Менеджер завода для заявок: кто и куда отправлять заявку
- [ ] Оператор персональных данных: юрлицо, от имени которого политика

Имена файлов: латиницей, без пробелов, например `sgr_bad.pdf`.
